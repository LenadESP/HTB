# 🛠️ HTB Tools

> Automation scripts for repetitive HackTheBox tasks — because life's too short to run nmap and ffuf sequentially.

Built by a self-taught 16 y/o on his HTB grind. Nothing fancy. Just scripts that save time and let me focus on the parts that actually require a brain.

---

## ⚙️ Setup

```bash
git clone https://github.com/yourusername/htb-tools.git
cd htb-tools
chmod +x **/*.sh
```

**Requirements:** `nmap`, `ffuf`, your wordlists of choice, and a victim machine.

This repo grows as I find more things worth automating. Scripts get added when I catch myself doing the same thing manually for the third time.
