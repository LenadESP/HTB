## What is it
It's a tool ran in the pwnd machine, used to test Privilege Escalation

---
## What does it enum/reckon
It runs a set of tests to check for vulnerable files, configs, cronjobs, or users inside a machine. LinPEASS for Linux machines, WinPEASS for Windows machines.
